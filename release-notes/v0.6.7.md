# SSH MountMate v0.6.7

Unify capacity and inode quota displays, fix password profiles that still requested an old
private key, and make imported OpenSSH connections follow their configuration file.

- Capacity and inode bars use the hard limit as their range. A thin neutral divider marks a
  lower soft limit; equal soft and hard limits have no divider. Only the used portion beyond
  the soft limit shows a subtle pulsing star, while keeping the selected accent color.
- Settings accepts a custom accent color in #RRGGBB format, with live preview.
- Switching to password authentication clears inactive key fields. Managed SSH profiles no
  longer validate, copy, or export a private key for password authentication.
- Imported OpenSSH connections use the original config and Host alias without overriding
  them with cached host, user, port, or identity fields. The interface clarifies that plain
  OpenSSH is non-interactive; use Native SFTP for saved passwords or Interactive shared SSH
  for terminal login prompts.
- Native SFTP prefers existing host-and-port bindings in known_hosts before scanning a
  new host key. Host-key mismatch checks remain enabled.
- Windows x64 and ARM64 binaries now embed the official WinFsp 2.1.25156 installer,
  pinned by SHA-256. The setup prompt explains the underlying mounting component and offers
  Install component / Later. No additional download is needed. Installation requests Windows
  administrator approval and resumes a pending mount when successful. Linux and macOS do not
  include the installer.
- Mounted connections keep the same settings layout. Locked controls are greyed out, with a
  hover tip explaining that you must unmount before editing.

For imported profiles using plain OpenSSH, update the source SSH config to change connection
settings. Saved target fields continue to apply to Native SFTP and interactive shared SSH.

统一容量与 inode 配额显示，修复密码登录仍要求旧私钥的问题，并让导入的 OpenSSH 连接
实际沿用原配置文件。

- 容量和 inode 均按硬配额显示进度。软配额较低时显示中性细分割线，软硬配额相同时不画线。
  仅在已用量超过软配额的区间显示轻微呼吸闪烁的星形标记，进度条保留所选强调色。
- 设置支持输入 #RRGGBB 自定义强调色，并即时预览。
- 切换为密码登录后清除不再使用的私钥字段；托管 SSH 配置不再检查、复制或写入旧私钥。
- 导入的 OpenSSH 连接直接使用原 config 和 Host 别名，不再被旧的主机、用户名、端口、密钥
  快照覆盖。界面明确说明普通 OpenSSH 为非交互登录；保存密码可用原生 SFTP，终端登录提示
  可用交互式共享 SSH。
- 原生 SFTP 优先使用 known_hosts 中已有的主机与端口绑定，再考虑首次扫描。继续校验主机密钥。
- 仅 Windows x64 和 ARM64 二进制内置官方 WinFsp 2.1.25156 安装包，通过 SHA-256 固定版本。
  友好弹窗解释底层挂载组件的用途，提供「安装组件 / 稍后」，无需再次下载。
  安装会请求 Windows 管理员授权，成功后自动继续刚才的挂载。Linux 和 macOS 不包含安装包。
- 已挂载连接的设置保留原有布局，锁定控件置灰，悬停提示先取消挂载再编辑。

导入连接使用普通 OpenSSH 时，请修改源 SSH config 来调整连接参数。原生 SFTP 和交互式
共享 SSH 继续使用已保存的目标字段。
