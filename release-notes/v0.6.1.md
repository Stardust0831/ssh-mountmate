# SSH MountMate v0.6.1

This patch release is based on v0.6.0 and includes all of its changes. It also adds the
SSH MountMate logo asset and prompts Windows users to install WinFsp at startup when it is
missing, opening the official installation page after confirmation.

本补丁版本以 v0.6.0 为基线，包含 v0.6.0 的全部更新。新增 SSH MountMate logo 资源；Windows
启动时检测到缺少 WinFsp 会立即提示用户，并在确认后打开官方安装页面。
