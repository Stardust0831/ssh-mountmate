# SSH MountMate v0.6.12

- Add multiple remote-to-local mount mappings to one connection, sharing authentication and interactive SSH login. Expand the connection card for independent mount/unmount, directory opening, logs, capacity, inode and transfer status, or operate on the whole group.
- Keep shared connection fields and active mapping rows read-only while mounted; allow adding mappings and editing or removing idle rows. Reject duplicate local destinations and preserve each mapping's runtime and cache identity.
- Preserve existing single-mount profiles, credentials and caches. Startup and batch mount actions include every mapping; installing the bundled WinFsp component resumes all queued mappings.
- Export and import all mappings as JSON. Schema 2 exports require v0.6.12 or later; old exports remain supported. Imported SSH config connection fields stay read-only while directory mappings remain editable.
- Extend regression coverage for shared authentication, mapping edits during active mounts, stable IDs and export compatibility, plus real Linux and Windows mounting of two directories with independent unmounting.

---

- 同一连接支持多组远程目录与本地挂载位置，共用认证信息和交互式 SSH 登录。展开卡片后可逐个挂载、取消挂载、打开目录、查看日志、容量、inode 和传输状态，也可整组操作。
- 挂载时共用连接字段和活动路径行保持只读；仍可新增映射、编辑或删除闲置行。拒绝重复本地位置，保留各映射的运行标识与独立缓存。
- 兼容旧单挂载配置，保留凭据和缓存；开机与批量挂载覆盖全部映射。安装内置 WinFsp 后会继续全部待挂载操作。
- JSON 导入、导出包含全部映射；新版 schema 2 导出需要 v0.6.12 或以上版本读取，仍兼容旧导出。SSH config 导入的连接字段保持只读，目录映射可以编辑。
- 增加共享认证、活动挂载下编辑路径、稳定标识和配置往返测试，并扩展 Linux、Windows 真实双目录挂载与独立卸载测试。
