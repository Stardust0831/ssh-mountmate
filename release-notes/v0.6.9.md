# SSH MountMate v0.6.9

- Add connection JSON export in Settings and a unified batch import preview for SSH configs and SSH MountMate exports. Passwords and private key contents are excluded.
- Consolidate Windows data under `%LOCALAPPDATA%\ssh-mountmate`, migrating previous configuration, caches, state and managed dependencies when no old mount or update is active.
- Add a Windows uninstall action that removes the running executable, application data, update helpers and transaction leftovers, saved credentials and application integrations after confirmation. External SSH files, exported backups outside application directories and shared WinFsp are retained.
- Imported SSH configs default to OpenSSH. Keep the same editor layout, with fields read-only except the connection name. Rename “Transport” to “Authentication method”.
- Add Windows downloads with the version in the executable filename. ZIP filenames and their canonical executable remain compatible with older updaters; later updates started from this version install a versioned executable.
- Remove the quota bar's animated dots, retaining the accent color and neutral soft-quota divider for capacity and inode quotas.

---

- 设置新增连接 JSON 导出；“批量导入”统一支持 SSH 配置文件和 SSH MountMate 配置文件，预览后导入或覆盖，不导出密码与私钥内容。
- Windows 应用数据统一为 `%LOCALAPPDATA%\ssh-mountmate`；旧挂载或更新结束后，自动迁移旧配置、缓存、状态和托管依赖。
- 设置新增 Windows 卸载按钮，确认后退出并清理程序本体、应用数据、更新 helper 与更新残留、已存凭据及系统集成。外部 SSH 文件、应用目录外的导出备份与共享 WinFsp 保留。
- 从 SSH 配置导入时默认使用 OpenSSH，保持原有表单布局，除名称外的连接字段置灰只读；“传输方式”改为“认证方式”。
- Windows 单文件下载名称带版本号；ZIP 继续兼容旧更新器，从本版发起的后续自动更新会安装带版本号的程序文件。
- 移除配额条上的闪烁小点，容量和 inode 继续保留强调色及中性的软配额分割线。
