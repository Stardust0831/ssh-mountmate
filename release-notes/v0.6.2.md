# SSH MountMate v0.6.2

This patch connects the brand icon to the application and release packages, makes edits to
imported SSH connections take effect, and protects interactive mounts during updates.

- Use the brand icon in application windows and the tray, embed it in Windows executable
  resources, and include it in the macOS app bundle. Linux GUI startup registers a per-user
  launcher and hicolor icon; launching the executable again after moving it updates the launcher.
- Apply saved host, username, port, and authentication choices to imported connections. Native
  SFTP no longer overwrites complete saved profiles with values from the source SSH config;
  OpenSSH retains alias-based routing while applying saved connection targets.
- Put the app-managed SSH `Include` in global scope and migrate entries previously appended
  inside `Host` or `Match` blocks. Also recognize the valid `Host=alias` and `Include=path` forms.
- Block update installation and application replacement while interactive mounts, mount
  operations, or queued logins still depend on the GUI. Finish or cancel pending login, wait for
  uploads to finish, and unmount interactive connections before updating. Native SFTP and OpenSSH
  mounts can continue through the GUI restart.
- Prefer Lustre project quota whenever the connection supports SSH capacity queries, then try
  local mountpoint capacity, `rclone about`, and remote `df`. Interactive queries reuse the
  verified shared SSH session.
- Make native credential-store CI checks fail if the intended test does not run. Add Windows/macOS
  package icon checks and a Linux window and desktop icon verification script.
- Correct the documentation for the shared expandable transfer window, selected login-startup
  connections, and credential storage. System credential-store mode still retains a reversible
  `rclone obscure` compatibility copy in private configuration, including newly saved secrets;
  system-store read failures do not fall back to that copy.

When upgrading from v0.6.1, manually unmount interactive connections first: the new update guard
only takes effect after running v0.6.2.

本补丁将品牌图标接入应用和发布包，让导入 SSH 连接后的编辑实际生效，并保护更新期间的
交互式挂载。

- 应用窗口和托盘使用品牌图标，Windows 可执行文件嵌入图标资源，macOS 应用包包含图标。
  Linux GUI 启动时注册当前用户的启动器和 hicolor 图标；移动程序后再次启动会更新启动器路径。
- 导入的连接使用保存的主机、用户名、端口和认证选择。原生 SFTP 不再用源 SSH config
  覆盖完整的已保存配置；OpenSSH 在应用保存的连接目标时，保留别名对应的路由配置。
- 将应用托管的 SSH `Include` 放在全局范围，并迁移旧版追加到 `Host` 或 `Match` 块内的
  条目。同时识别合法的 `Host=alias`、`Include=path` 语法。
- 存在依赖 GUI 的交互式挂载、挂载操作或排队登录时，阻止安装更新和程序替换。请先完成
  或取消待处理登录、等待上传完成并卸载交互式连接，再更新。原生 SFTP 和 OpenSSH 挂载
  可以在 GUI 重启期间继续运行。
- 支持 SSH 容量查询的连接优先读取 Lustre project quota，再依次尝试本地挂载点容量、
  `rclone about` 和远端 `df`。交互式查询复用已验证的共享 SSH 会话。
- 修正原生凭据库 CI 检查，目标测试未实际运行时会失败。新增 Windows/macOS 打包图标
  检查，以及 Linux 窗口和桌面图标验证脚本。
- 修正文档中的共享可展开传输窗口、选定连接登录自启和凭据存储说明。系统凭据库模式仍
  会在私有配置中保留可逆的 `rclone obscure` 兼容副本，新保存的秘密也一样；系统凭据
  读取失败时不会回退使用该副本。

从 v0.6.1 升级前，请手动卸载交互式连接：新的更新保护只有在运行 v0.6.2 后才会生效。
