# SSH MountMate v0.6.19

- Fix missing Lustre soft-quota and inode information with native SFTP password or private-key login. Capacity refresh now reads complete quota details from the running mount backend and reuses its verified SSH session, without requiring a separate system SSH login.
- Preserve block and inode soft/hard limits through rclone's `about` response. Each mount queries its own remote directory; ordinary filesystem statistics remain available when no usable project quota exists.
- Parse Lustre rows correctly when a long filesystem path wraps onto a separate line.
- **Remount after upgrading** to start the new bundled rclone. Existing mount processes cannot gain the new quota fields until restarted.

---

- 修复原生 SFTP 使用密码或私钥登录时缺失 Lustre 软配额和 inode 信息：容量刷新直接从正在运行的挂载进程读取完整配额，并复用已验证的 SSH 会话，不再依赖另一条系统 SSH 登录。
- rclone 的容量响应保留容量与 inode 的软硬配额。每个挂载点查询自己的远端目录；没有可用 project 配额时仍显示普通文件系统统计。
- 修复 Lustre 文件系统路径较长、输出换行时的配额列解析。
- **更新后请取消挂载并重新挂载**，让挂载进程使用新版内置 rclone。已运行的旧进程需要重启才能返回新增配额字段。
