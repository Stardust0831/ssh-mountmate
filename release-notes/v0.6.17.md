# SSH MountMate v0.6.17

- Fix native SFTP host-key confirmation when an existing OpenSSH record uses the equivalent default-port spelling `[host]:22`. Confirming a changed key now removes both equivalent stale records while preserving unrelated hosts.
- Speed up normal mounts with an existing trusted key. A short keyscan can detect a changed server key early; if that probe is unavailable, the mount proceeds to the authoritative rclone SSH handshake instead of waiting through a second full discovery attempt.
- Keep first-use and actual mismatch recovery behavior from v0.6.16: show the server fingerprint, require explicit confirmation, and provide a retry dialog when no public key can be obtained.

---

- 修复原生 SFTP 的主机指纹确认：已有 OpenSSH 记录使用默认端口的等价写法 `[主机]:22` 时，确认新指纹会同时清理旧记录，并保留其他主机。
- 缩短已有可信指纹连接的挂载等待：先用短时 `ssh-keyscan` 快速检查变化；探测不可用时直接交给 rclone 进行权威 SSH 握手，不再串行等待第二次完整探测。
- 保留 v0.6.16 的首次连接和实际指纹变化恢复流程：展示服务器指纹、必须明确确认；无法获取公钥时提供重试弹窗。
