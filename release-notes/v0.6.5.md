# SSH MountMate v0.6.5

Improve capacity and transfer reporting for cached SSH mounts.

- Use the Lustre project hard block quota as the displayed capacity total.
- Show the Lustre soft quota as a warning marker and hover detail without treating it as exhausted
  hard capacity.
- Keep completed upload bytes in the current transfer session to avoid progress jumps caused by
  rclone removing completed files from `vfs/queue`.
- Handle Lustre quota output markers such as `*`, `-`, and `--`.

Improve cached upload progress while preserving rclone's normal write-back and consistency behavior.
Windows, macOS, and Linux packages are available for x64 and ARM64.

# SSH MountMate v0.6.5

改善缓存 SSH 挂载的容量和传输状态显示。

- 使用 Lustre 项目硬块配额作为容量总量。
- 用警告细线和悬停提示显示 Lustre 软配额，不再把软配额当作硬容量耗尽。
- 在当前传输会话中保留已完成文件的累计字节，避免 rclone 从 `vfs/queue` 移除文件后进度条跳回或分母缩小。
- 兼容 Lustre 配额输出中的 `*`、`-` 和 `--` 标记。

改进缓存上传进度，同时保留 rclone 原有的写回和一致性语义。提供 Windows、macOS、Linux 的
x64 和 ARM64 安装包。
