# SSH MountMate v0.6.21

- Make SSH connection and login failures easier to identify: authentication rejection, connection timeout/refusal, address resolution, unusable private keys, fingerprint verification and early disconnects appear before log paths and startup notices, with focused troubleshooting guidance.
- Keep SFTP startup errors distinct from login failures and retain the original diagnostics. Error explanations use the existing connection attempt, without an extra SSH login.
- Allow idle connections imported from SSH config to switch between OpenSSH and interactive SSH. Fields supplied by the SSH file remain read-only, and mounted or starting connections keep their editing protection.
- Speed up release CI with verified Rust dependency and patched-rclone caches, parallel quality/platform checks, and a single final application build for Windows and Linux. Full package integration, update/rollback and signature checks remain required.

---

- 更清楚地显示 SSH 连接和登录失败原因：认证未通过、连接超时或被拒绝、地址解析失败、私钥不可用、指纹校验失败及登录前断开，会优先于日志路径和启动通知显示，并附对应排查建议。
- 继续区分 SFTP 启动异常与登录失败，保留原始诊断信息；错误分析直接使用本次连接结果，不额外发起 SSH 登录。
- 修复 SSH 配置来源误冻结连接方式的问题：未挂载时可切换 OpenSSH／交互式 SSH。地址、账号等来自配置文件的字段仍只读；已挂载或正在启动的连接继续禁止编辑。
- 优化发布 CI：复用经过验证的 Rust 依赖与定制 rclone 缓存，并行执行质量检查和平台构建，Windows/Linux 只编译一次最终程序；完整安装包、挂载、更新回滚和签名验证仍全部保留。
