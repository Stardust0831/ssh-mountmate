# SSH MountMate v0.7.0-beta.1

This is the first preview of the 0.7 series, bringing SAI account setup, authorized directory selection, clearer program feedback, and more reliable mount workflows.

- Sign in with a SAI account, approve SSH key enrollment in the browser, and choose the home, organization, or shared project directories returned by the portal. Directory availability and access depend on the site's capabilities and permissions. Copy buttons provide a manual fallback for login links and verification codes.
- Follow login, mount, transfer, and error messages in a dedicated, resizable program log with consistent text rendering.
- Treat remote quota and free-space snapshots as advisory for uploads, accommodating elastic storage quotas. Remote filesystem permissions and actual server write failures remain authoritative.
- Improve automatic Windows drive selection, occupied mount-folder detection, and mount readiness reporting. Manual OpenSSH connections can select a private key directly.
- Invalidate old synchronization evidence as soon as a transfer query fails, and ignore replies from an earlier mount session. Single, batch, and command-driven unmounts share the same synchronization check; the dialog offers wait for uploads, unmount now, and cancel.
- Keep unsaved editor/settings input and SAI authorization active while viewing transfers, then return to the previous workflow. Group mount observations, editor state, and configuration persistence into focused modules.

Install this preview manually from the assets below; stable-channel clients continue to receive stable releases. Preview clients can discover later previews and stable versions. Existing mounts must be unmounted and mounted again to use the updated bundled engine.

Please exercise SAI sign-in and directory selection, NAS/SAI uploads, automatic drive assignment, and editor/transfer navigation on your own system. Automated checks use temporary test servers and do not replace validation against your site's network and permissions.

这是 0.7 系列的首个预发布版本，集中带来 SAI 账号配置、授权目录选择、更清晰的程序反馈，以及更可靠的挂载操作流程。

- 使用 SAI 账号登录，在浏览器确认 SSH 公钥授权，并选择门户返回的家目录、组织目录或共享项目目录。可用目录与访问能力取决于站点开放的功能和实际权限；登录链接、验证码提供复制入口，方便手动完成授权。
- 通过独立、可调整大小的程序日志区域查看登录、挂载、传输和错误消息，并统一文字显示。
- 上传时将远端配额与剩余空间快照作为参考，适应弹性存储配额；实际文件权限和服务端写入失败仍按原有机制处理。
- 改善 Windows 自动盘符选择、已占用挂载目录检查与挂载就绪反馈；手动 OpenSSH 连接可直接选择私钥。
- 传输查询首次失败就使旧同步证据失效，卸载或重新挂载后忽略旧会话回包。单个、批量和命令触发的卸载统一判断同步状态，确认窗口明确提供“上传完成后卸载 / 立即卸载 / 取消”。
- 查看传输时保留未保存的编辑/设置内容和 SAI 授权流程，返回后继续操作；挂载观测、编辑状态与配置保存收拢到各自模块。

请从下方附件手动安装此预发布版；稳定版更新通道仍只接收正式版。预发布版可以发现后续预发布及正式版本。已有挂载需要卸载后重新挂载，才能使用更新后的内置引擎。

建议在自己的环境重点测试 SAI 登录与目录选择、NAS/SAI 文件上传、自动盘符分配，以及编辑页和传输页往返。自动化测试使用临时测试服务器，不能代替实际站点网络和权限验证。
