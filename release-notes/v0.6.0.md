# SSH MountMate v0.6.0

This stable release adds clearer connection transport guidance and a shorter VFS write-back
preset for users who want uploads to become eligible sooner.

- Added a `1s` write-back delay preset.
- Added a bilingual help tooltip for the transport selector, explaining its distinction from
  authentication and how OpenSSH-based connections obtain credentials.

---

本正式版改进了连接传输方式说明，并为希望更快开始上传的用户提供更短的 VFS 回写延迟选项。

- 新增 `1s` 回写延迟预设。
- 为传输方式选择器增加中英文帮助提示，说明它与身份验证的区别，以及 OpenSSH 连接如何获取凭据。
