# SSH MountMate v0.6.11

- Replace the Windows uninstall button with automatic update-file maintenance. Connection import and export remain in Settings.
- On startup, wait for an active update to commit and its helper to exit before removing updater-owned downloads, extracted copies, unused helpers and stale markers. The first upgrade from an older version into v0.6.11 also cleans previous leftovers, including the legacy Windows profile.
- Release redundant download and extraction files as soon as a new update is staged, and clean them on preparation failures. Serialize maintenance with pending update preparation; retain busy files for a later launch.
- Preserve connection settings, credentials, SSH files, dependencies, mount caches and queued uploads. Normal updates delete the replaced executable backup only after health confirmation; interrupted recovery backups and manually downloaded copies are retained.
- Test cleanup during the packaged GUI update flow, along with rollback, legacy-profile cleanup, concurrent preparation and linked-path protection.

---

- 取消 Windows 设置中的“卸载 SSH MountMate”按钮，改为自动维护更新文件；连接配置的导入、导出保留。
- 启动时先等待进行中的更新成功提交、更新助手退出，再清理更新包、解压副本、闲置助手与过期更新标记。从旧版更新到 v0.6.11 后首次启动即可清理以前的遗留文件，也覆盖旧 Windows 数据目录。
- 此后的更新在安装副本准备好后立即释放下载与解压文件，准备失败也会回收临时文件。清理与更新准备互斥，暂时被占用的文件留待后续启动重试。
- 保留连接设置、凭据、SSH 文件、依赖、挂载缓存和待上传数据。正常更新只在新版确认健康后删除被替换的旧程序备份；异常中断的恢复备份与手动下载的程序副本保留。
- 打包 GUI 更新测试覆盖首次升级清理，并验证失败回滚、旧目录清理、并发更新准备和链接路径保护。
