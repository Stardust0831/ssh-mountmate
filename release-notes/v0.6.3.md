# SSH MountMate v0.6.3

Fix stable update checks reporting `MissingManifest` when the GitHub API is rate-limited or
unavailable. The fallback now retrieves and verifies the release's official signed manifest;
signature, version, channel, platform, size, and SHA-256 checks still apply before installation.

If v0.6.1 or v0.6.2 still blocks the update with this error, retry after API access recovers or
manually download and install v0.6.3 once. The corrected fallback only takes effect after the new
version is installed. Wait for uploads to finish and unmount interactive shared SSH connections
before upgrading.

---

修复 GitHub API 限流或不可用时，稳定版本更新检查错误报告 `MissingManifest` 的问题。
回退路径现在会获取并验证该版本的官方签名清单；安装前仍须通过签名、版本、发布通道、
平台、文件大小和 SHA-256 校验。

如果 v0.6.1 或 v0.6.2 仍因该错误阻止更新，请在 API 恢复后重新检查，或手动下载并安装
一次 v0.6.3。新的回退逻辑只有在安装新版本后才会生效。升级前请等待上传完成，并卸载
交互式共享 SSH 连接。
