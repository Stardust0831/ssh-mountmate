# SSH MountMate v0.6.14

- Reduce the default VFS write-back delay from **5 seconds to 1 second**, so closed files become eligible for upload sooner. The simultaneous-upload default remains 12.
- On upgrade, migrate the previous 5s value to 1s while preserving other values. A user-selected 5s after migration remains 5s. Changes apply on the next mount; active mounts continue with their existing settings.
- Clarify platform dependencies: macOS can use the experimental built-in NFS backend without macFUSE/FUSE-T. Windows still uses the bundled WinFsp installer; the current NFS backend cannot be used there directly. Linux continues to use FUSE.

---

- 默认 VFS 写回延迟从 **5 秒缩短为 1 秒**，文件关闭后更快进入可上传状态；上传并发默认仍为 12。
- 升级时将原值 5s 迁移为 1s，其他值保留；升级后手动选回 5s 也会保留。下次挂载时生效，已有挂载继续使用原设置。
- 补充平台依赖说明：macOS 可选实验性内置 NFS，免装 macFUSE/FUSE-T；Windows 仍使用内置 WinFsp 安装包，当前 NFS 后端不能直接用于 Windows；Linux 继续使用 FUSE。
