# SSH MountMate v0.6.10

- When uninstalling just after an automatic update, wait up to five seconds for the update helper to finish instead of immediately showing a generic mount/update warning. Active mounts are still protected; no processes are forcibly stopped.
- Report the blocking process name, PID and activity if application files remain in use. Distinguish update finalization, active mounts and other background tools.
- Stop treating a profile path in a file manager/editor command line or a reused PID in an old mount record as proof of an active mount or update. Preserve checks for verified mounts, orphaned mounts and running application executables.
- Extend packaged update tests to check that an idle updated GUI does not leave the uninstall process check blocked after the helper exits.

---

- 自动更新后立即卸载时，最多等待 5 秒，让更新 helper 完成收尾，避免直接显示笼统的“挂载或更新仍在运行”。活动挂载仍会阻止卸载，不强制结束进程。
- 若应用文件仍被占用，提示具体进程名、PID 和原因，区分更新收尾、活动挂载与其他后台工具。
- 资源管理器或编辑器参数里的配置路径，以及旧挂载记录中被复用的 PID，不再直接判定为活动挂载或更新；仍保护确认存在的挂载、遗留挂载和运行中的应用文件。
- 打包更新测试新增卸载前置检查，验证 helper 退出后，空闲的新版界面不会仅因更新启动参数而触发拦截。
