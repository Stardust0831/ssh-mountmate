# SSH MountMate v0.6.4

Improve responsiveness when opening **Add connection** and **Settings**. Windows drive choices
are now read once from the system drive list instead of opening each drive root during rendering,
avoiding waits on disconnected mapped drives. Idle service polling no longer repeatedly rebuilds
the interface; polling remains active for mounts, transfers, interactive login, and update downloads.

- Preserve trailing separators while typing remote paths such as `data/logs/`.
- Keep the custom mountpoint textbox visible while typing a Windows drive prefix such as `C:`.
- Debounce custom mountpoint checks and limit them to one worker; stale results cannot replace the
  latest input.
- Retain Native authentication choices when switching transports, protect edits during saving,
  and add Tab / Shift+Tab navigation within the active form or dialog.
- Validate custom numeric input without silently changing `1.5` into `15` or `-1` into `1`.
- Preserve custom SAI connection names and clarify when saved credentials must be entered again.
- Bound Linux GTK tray event processing so a continuously ready source yields to the window.

Windows, macOS, and Linux packages are available for x64 and ARM64. Wait for uploads to finish
and unmount interactive shared SSH connections before upgrading. Older v0.6.1/v0.6.2 clients that
report a missing update manifest may need a one-time manual installation.

改善打开 **添加连接** 和 **设置** 后的响应速度。Windows 盘符选项改为打开页面时读取一次
系统盘符列表，不再在界面绘制时逐个访问盘根目录，避免等待失联的网络映射盘。空闲服务不再
频繁触发整页重建；挂载、传输、交互式登录和更新下载仍按需要刷新。

- 输入 `data/logs/` 等远程路径时，保留末尾斜杠，保存时再规范化。
- 自定义挂载路径输入到 `C:` 时，文本框保持可见，可继续输入完整 Windows 路径。
- 挂载路径检查增加防抖，同时最多执行一个检查，旧结果不会覆盖最新输入。
- 切换连接方式时保留原生认证选择，保存期间保护表单输入，并支持在当前表单或弹窗内使用
  Tab / Shift+Tab 切换输入框。
- 自定义数值保留原始输入并提示校验错误，不再把 `1.5` 静默改成 `15` 或把 `-1` 改成 `1`。
- 保留用户自定义的 SAI 连接名称，并明确提示何时需要重新输入已保存的凭据。
- 限制 Linux GTK 托盘单次事件处理量，避免持续事件占用窗口线程。

提供 Windows、macOS、Linux 的 x64 和 ARM64 安装包。升级前请等待上传完成，并卸载交互式
共享 SSH 连接。v0.6.1/v0.6.2 若仍提示更新清单缺失，可能需要手动安装一次。
