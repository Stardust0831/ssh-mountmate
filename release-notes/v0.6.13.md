# SSH MountMate v0.6.13

- Restore the `$HOME` / `/` selector and relative path field on every mount mapping, using the same controls as the original row. Mounted paths remain read-only.
- Always show mount mappings on connection cards; remove the expand/collapse toggle while retaining individual and group actions.
- Add **Custom** to the Accent menu and show the color input only when selected. Preserve existing custom colors, and remember the custom value when switching to a preset.
- Increase default simultaneous file uploads to **12**. Upgrade the old value of 4 to 12 while preserving other valid values; users can still select 1–32. Upload settings take effect on the next mount.

---

- 所有挂载点恢复 `$HOME` / `/` 选择框与子路径输入框，统一原始行和新增行的控件；挂载状态下仍只读。
- 连接卡片始终显示全部挂载点，移除展开、折叠开关，保留单独与整组操作。
- 在“强调色”下拉菜单中加入“自定义”，仅选中时显示颜色输入框。兼容旧自定义颜色，切换预设后也记住上次自定义值。
- 默认同时上传文件数调整为 **12**。升级时将原值 4 调整为 12，其他有效值保留，仍可在 1–32 之间选择；下次挂载时生效。
